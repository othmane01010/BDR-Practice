# BDR-Practice 🗄️

Welcome to my Database Design and Relational Databases (BDR) practice repository. This repository serves as a portfolio of my learning journey, where I document various database concepts, conceptual models, and SQL implementations.

## 📌 Overview

For each project or exercise in this repository, you will find:
* **MCD (Modèle Conceptuel de Données):** Conceptual data models and business rules.
* **MLD (Modèle Logique de Données):** Relational models derived from the MCD.
* **SQL Scripts:** Structured queries for creating tables (`CREATE TABLE`), establishing constraints, and seeding sample data.
